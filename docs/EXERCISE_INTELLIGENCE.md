# RepFlow Exercise Intelligence (V14A)

This release establishes the structured foundation for program generation.

## Included
- versioned movement taxonomy
- generator metadata on every exercise
- deterministic ranking and compatibility scoring
- duplicate-cluster prevention
- equipment, difficulty, fatigue and contraindication filters
- admin readiness dashboard
- quality-flag schema

## Deliberate limit
The catalogue is not inflated to 1,000 exercises in one unreviewed import. The existing library is upgraded first. Additional exercises should be added in reviewed batches with valid metadata, alternatives and duplicate clusters.

## Next module
V14B will use this foundation to build balanced sessions and enforce time, volume and movement constraints.
